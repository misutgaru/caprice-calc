# 왕의 카프리스 계산기

A calculator for the King's Caprice event in Shop Titans.

Shop Titans의 **왕의 카프리스(King's Caprice)** 이벤트를 위한 계산기입니다. 내 일꾼 레벨과 버프를 한 번 입력해 두면 청사진 1,626개의 **실제 제작 시간**과 **시간당 호의(Favor)**를 계산해서 순위로 보여 줍니다.

---

## 주요 기능

- **실제 제작 시간 계산:** 일꾼 레벨, 길드 부스트, 제작 업그레이드, 고급 연구까지 반영합니다. 게임과 같은 방식으로 초 단위 이하는 버립니다.
- **시간당 호의 순위:** 카프리스 요청에 맞는 아이템 중 어떤 것을 만들어야 가장 효율적인지 보여 줍니다.
- **요청 칸별 1위 표시:** 왕의 요청 4칸(특별 요청 1칸 + 종류 3칸)을 채우면 칸마다 가장 효율 좋은 아이템이 바로 나옵니다.
- **한국어 · 영어 아이템 이름:** 두 언어가 함께 표시되고, 검색도 둘 다 됩니다.
- **설정 자동 저장 · 백업:** 브라우저에 자동 저장되고, 설정 코드로 다른 기기에 옮길 수 있습니다.

---

## 처음 시작하기

1. 페이지를 열고 **일꾼 · 버프 설정** 탭으로 이동합니다.
2. 아래 [설정 방법](#설정-방법)을 보고 값을 입력합니다. 입력하는 즉시 저장됩니다.
3. **순위표** 탭으로 돌아와 카프리스 요청을 채우고, 위에서부터 만들면 됩니다.

> 처음 열면 모든 일꾼이 Lv 30인 **예시 값**으로 계산됩니다. 일꾼 레벨을 한 번만 입력하면 그 뒤로는 내 값으로 계산돼요.

---

## 설정 방법

### 일꾼 레벨

- 일꾼 19명의 레벨을 입력합니다. **없는 일꾼은 0**으로 두세요.
- 레벨 옆에 그 레벨의 제작 속도 보너스가 표시됩니다 (예: `속도 −52%`). Lv 46 이상이면 T15+ 추가 보너스도 함께 표시됩니다.
- 레벨업하면 그 일꾼 칸만 고치면 됩니다.
- 학자, 기술자, 음유시인 같은 **유료 일꾼**은 레벨을 1 이상 넣으면, 그 일꾼과 함께 받는 청사진(완드, 석궁, 총, 악기 등)이 자동으로 보유 처리됩니다.

### 제작 버프

| 항목 | 넣는 값 |
|---|---|
| **길드 부스트 제작 시간 감소 %** | 길드에서 제작 속도 부스트를 켰을 때만 그 % (예: 25). 꺼져 있으면 0 |
| **기타 제작 시간 감소 %** | 평소에는 **0**. 24시간 모디파이어 "Fast Craft, Quest & Rest"가 열린 날에만 25 |
| **기본 제작 업그레이드 단계** | 청사진 마일스톤을 보통 몇 단계까지 열었는지. 제작 시간 감소는 대부분 **1단계**에 있어서, 몇 번이라도 만들어 봤다면 1 이상이면 됩니다 (5 = 마스터) |
| **기본 스타포지 단계** | 마스터 이후 추가로 열리는 단계. 신경 써서 올린 적이 없으면 **0** |
| **기본 각성(어센션) 단계** | 각성을 안 했으면 **0** |

> 여기서 넣는 단계는 **모든 아이템의 기본값**입니다. 아이템마다 다르면 [아이템별 개별 설정](#아이템별-개별-설정)에서 따로 지정하세요.

### 고급 연구

- T14 이상 아이템의 제작 시간을 **절반(−50%)**으로 줄여 주는 연구입니다. 종류별로 따로 엽니다.
- 게임에서 종류별 고급 연구 화면을 보고 맞춰 고르세요.
  - 연구를 안 열었으면 **없음**
  - 첫 노드("제작 시간 감소")만 열었으면 **T14**
  - "T15에 적용"까지 열었으면 **T14–15**
  - "T16에 적용"까지 열었으면 **T14–16**
- 원소와 영혼은 따로 있습니다.

### 보유 범위 · 호의 가정

| 항목 | 설명 |
|---|---|
| **아이템 이름 표시** | 자동(모바일 한국어 · PC 영어) / 한국어 먼저 / 영어 먼저 |
| **제작 가능한 최고 티어** | 내가 만들 수 있는 가장 높은 티어. 이보다 높은 티어는 순위표에서 빠집니다 |
| **프리미엄 · 상자 청사진** | 기본은 **전부 보유한 것으로 계산**. 갖고 있는 것만 보고 싶으면 "보유 체크한 것만"으로 바꾸면 체크 목록이 나타납니다 |
| **예상 품질** | 호의 배수: 일반 ×1 · 고급 ×1.25 · 완벽 ×1.5 · 에픽 ×2 · 전설 ×3 |
| **기본 멀티크래프트 확률 %** | 아이템 업그레이드에 있는 멀티크래프트는 자동으로 더해지므로 보통 0. 멀티크래프트는 호의가 2배입니다 |
| **동시에 돌리는 제작 슬롯 수** | 순위표 아래 "슬롯 합계 시간당 호의" 계산에 쓰입니다 |

## 순위표 사용법

### 카프리스 요청 채우기

화면 위쪽에 왕의 요청 4칸이 있습니다.

- **특별 요청 (금테):** 왕이 지정한 아이템 이름을 입력합니다. 한국어, 영어 모두 됩니다.
- **요청 종류 1~3:** 왕이 요청한 종류(검, 반지 등)를 고릅니다. "모든 무기"처럼 묶음도 고를 수 있습니다.
- **×2 체크:** 호의가 2배인 칸이면 체크합니다. 여러 칸에 동시에 해당하는 아이템은 배수가 더해집니다.

칸마다 아래에 **그 칸의 1위 아이템**과 제작 시간, 시간당 호의가 바로 표시됩니다.

### 표 보기

- **시간당 호의 / 회당 호의 / 제작 시간** 머리글을 누르면 그 기준으로 정렬됩니다.
- **요청 품목만:** 켜 두면 요청에 맞는 아이템만 보입니다. 전체를 보고 싶으면 끄세요.
- **일꾼 레벨 부족도 표시:** 필요한 일꾼 레벨이 모자라 지금 못 만드는 아이템도 흐리게 보여 줍니다.
- **검색 · 종류 필터:** 이름(한국어/영어)이나 종류로 좁혀 볼 수 있습니다.

### 아이템별 개별 설정

표에서 아이템 행을 누르면 아래로 펼쳐지면서 다음이 보입니다.

- **계산 내역:** 기본 시간에 어떤 버프가 몇 배씩 곱해졌는지 한 줄씩 보여 줍니다.
- **제작 업그레이드 / 스타포지 / 각성:** 이 아이템만 단계를 따로 지정합니다. 바로 아래에 몇 단계에 어떤 효과가 있는지도 표시됩니다.
- **순위표에서 숨기기:** 없는 청사진이나 안 만들 아이템을 목록에서 뺍니다.
- **특별 요청 칸에 넣기:** 이 아이템을 금테 칸에 바로 넣습니다.

## 설정 백업 · 다른 기기로 옮기기

설정은 지금 쓰는 **브라우저에 자동 저장**됩니다. 다만 기기를 바꾸거나 브라우저 기록을 지우면 사라지니, 가끔 백업해 두세요.

### 백업하기

1. **일꾼 · 버프 설정** 탭 아래쪽의 **설정 백업 · 옮기기**로 갑니다.
2. **설정 코드 복사**를 누릅니다. `KC1:`로 시작하는 코드가 복사됩니다.
3. 메모장이나 카카오톡 "나에게 보내기" 등에 붙여넣어 보관합니다.

> 자동 복사가 안 되는 환경에서는 코드가 화면에 선택된 상태로 표시됩니다. 직접 복사하세요.

### 불러오기 (다른 기기 · 다른 브라우저)

1. 새 기기에서 계산기를 엽니다.
2. **설정 백업 · 옮기기**의 입력칸에 보관해 둔 코드를 붙여넣습니다.
3. **불러오기**를 누르면 일꾼 레벨, 버프, 숨긴 아이템, 아이템별 설정까지 그대로 옮겨집니다.

### 설정 초기화

설정 탭 맨 아래 **설정 초기화**를 누르고 한 번 더 확인하면 처음 상태로 돌아갑니다. 초기화 전에 코드를 백업해 두는 걸 추천합니다.

## 계산 방식

```
제작 시간 = 기본 시간
          × Π(1 − 제작 업그레이드 감소)
          × (1 − 길드 부스트)
          × (1 − 기타 버프)
          × Π(1 − 일꾼별 레벨 보너스)
          × Π(1 − 일꾼별 T15+ 보너스)     ← T15 이상 아이템만
          × (1 − 고급 연구 50%)           ← 적용된 티어만
          → 소수점 이하 버림

회당 호의   = 기본 호의 × 품질 배수 × (1 + 보너스 호의) × (1 + 멀티크래프트 확률) × 요청 배수
시간당 호의 = 회당 호의 × 3600 ÷ 제작 시간(초)
```

- 필요한 일꾼이 여러 명이면 각 일꾼의 보너스가 **곱해집니다**.
- 검, 완드, 약초, 지팡이(일꾼 1~3명) 아이템으로 게임 속 제작 시간과 초 단위까지 일치하는 것을 확인했습니다.

## 자주 묻는 질문

**게임과 제작 시간이 20~30% 정도 다르게 나와요.**
그 청사진의 제작 업그레이드(대개 1단계의 −20% 또는 −25%)가 아직 안 열렸을 가능성이 큽니다. 행을 눌러 **제작 업그레이드를 0단계**로 지정하세요. 나중에 열리면 "기본값"으로 되돌리면 됩니다.

**어떤 아이템이 순위표에 안 보여요.**
다음을 확인해 보세요.
- 위쪽 **요청 품목만**이 켜져 있지 않은지
- 그 아이템의 티어가 **제작 가능한 최고 티어**보다 높지 않은지
- 필요한 **일꾼 레벨이 부족**하지 않은지 ("일꾼 레벨 부족도 표시"를 켜면 보입니다)
- 예전에 **숨기기**를 하지 않았는지

**숨긴 아이템을 다시 보이게 하고 싶어요.**
지금은 개별로 되돌리는 버튼이 없어서, 설정 코드를 쓰거나 **설정 초기화**를 해야 합니다.

**아이템 이름이 게임과 달라요.**
한국어 이름은 커뮤니티 자료와 공식 사이트 한국어판에서 가져왔습니다. 다른 이름이 있으면 제보해 주세요.

## 업데이트 방법 (GitHub Pages)

새 청사진이 나와서 데이터를 갱신한 `index.html`을 받으면:

1. 이 저장소 첫 화면에서 **Add file → Upload files**를 누릅니다.
2. 새 `index.html`을 끌어다 놓고 **Commit changes**를 누릅니다.
3. 몇 분 뒤 페이지를 새로고침하면 반영됩니다.

설정은 브라우저에 저장돼 있어서, 파일을 바꿔도 그대로 남습니다.
